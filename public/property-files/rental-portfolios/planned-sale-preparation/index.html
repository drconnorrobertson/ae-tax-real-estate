Rental portfolios: Planned sale preparation

Evaluate the exit with the full depreciation and transaction history. Maintain a property-by-property map before aggregating results.

Preparation resource. Record completion does not determine eligibility, deductions or tax savings. Ask your qualified tax professional to resolve the facts and applicable rules.

What this file should establish

Collect original basis, improvements, prior depreciation, ownership and draft terms. Ask for an after-tax comparison with costs and timing. Do not treat a study's first-year projection as a complete lifetime benefit.

Maintain a property-by-property map before aggregating results.

A situation to work through

Several properties share a loan and management account.

For this situation, start with address register. Identify the period and legal owner before combining it with the other records. Keep the original source and explain any adjustments in a separate reconciliation.

Review point

A shared account does not replace property-level records.

The analysis ignores prior depreciation or changes in sale terms.

Question for the reviewer

How do the expected transaction and depreciation history change the comparison?

Expected handoff

A sale-review file with dated draft assumptions.

Separate facts supported by documents from estimates and unresolved assumptions. Assign each missing item to a responsible person and a date. Send the reconciliation alongside the source references so the reviewer can trace each conclusion.

Focused implementation guides

Resolve the related evidence question before carrying a planning assumption into implementation.

  • Property manager statement reconciliation: A manager collects rent and pays expenses before transferring cash to the owner.
  • Rental property tax escrow reconciliation: Mortgage payments include escrow deposits that differ from actual tax payments.
  • Rental sale asset register: A rental sale includes land, building and separately tracked assets.
